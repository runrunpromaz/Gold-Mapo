# Gold Mapo

Lightweight English-language offline gold mining arcade PWA.

## Play
Tap the game board, press Space or Down Arrow, or click Drop Hook. Collect gold and gems to meet the target within 60 seconds. Heavy rocks are worth fewer points. Complete levels to continue.

## GitHub Pages
1. Create repository `gold-mapo`.
2. Upload all files from this ZIP to repository root.
3. Settings > Pages > Deploy from a branch > main / (root).
4. Open `https://YOUR_USERNAME.github.io/gold-mapo/`.
5. Test PWA installation and offline play.

## Microsoft Store
Enter your GitHub Pages HTTPS URL at https://www.pwabuilder.com/ to generate a Windows MSIX/MSIXBUNDLE. Verify package identity, publisher, signing, capabilities, and Store requirements. This ZIP contains PWA source, not an MSIXBUNDLE.
